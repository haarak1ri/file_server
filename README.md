Данная программа представляет собой серверное приложение для управления файлами, реализованное на Java с использованием Spring Framework. Сервер предоставляет REST API для выполнения операций с файловой системой, позволяя клиентам удаленно управлять файлами и директориями через HTTP-запросы.
Ключевые возможности
1. Управление файловой структурой

   Просмотр содержимого директорий с получением метаданных (размер, дата изменения, тип)

   Рекурсивный поиск файлов по имени

   Создание новых директорий

   Удаление файлов и папок (рекурсивно)

2. Манипуляции с файлами

   Загрузка (upload) файлов на сервер

   Загрузка ZIP-архивов с автоматической распаковкой

   Копирование файлов и папок с автоматическим созданием копий

   Перемещение файлов и папок

   Скачивание отдельных файлов

   Скачивание целых папок в ZIP-архиве

3. Особенности реализации

   Защита от path traversal атак — все пути проверяются на выход за пределы корневой директории пользователя

   Потоковая обработка — файлы передаются потоково без загрузки всего содержимого в память

   Корневая директория пользователя — каждый пользователь работает в своей изолированной папке

   Профиль "local" — предназначен для локальной разработки и тестирования

Технические детали
Стек технологий

    Java с использованием NIO (New I/O) для работы с файловой системой

    Spring Framework — контекст приложения, dependency injection

    Apache Commons Compress — работа с ZIP-архивами (поддержка UTF-8 для кириллицы)

    REST API — взаимодействие через HTTP

Безопасность

    Валидация всех путей перед операциями

    Запрет выхода за пределы пользовательской директории

    Санитизация имен файлов для предотвращения обхода путей

Обработка ошибок

    Проверка существования файлов и директорий

    Обработка конфликтов имен (автоматическое создание копий)

    Информативные сообщения об ошибках

Архитектурные решения
Основные компоненты:

    LocalFileStorage — основной класс, реализующий интерфейс FileStorage

    UserRootFolderProvider — провайдер корневой директории текущего пользователя

    FileInfoDto — DTO для передачи информации о файлах через REST API

Принципы проектирования:

    Интерфейсная абстракция — возможность замены реализации хранилища (например, на облачное)

    Single Responsibility — каждый метод отвечает за одну конкретную операцию

    Стандартизация — использование Java NIO для кроссплатформенности

REST API Endpoints (ожидаемые)

Сервер предоставляет следующие типы запросов:

    GET /list — просмотр содержимого директории

    GET /search — рекурсивный поиск

    POST /upload — загрузка файла

    POST /upload-folder — загрузка и распаковка ZIP

    DELETE /delete — удаление файла/папки

    POST /move — перемещение

    POST /copy — копирование

    POST /create-folder — создание папки

    GET /download — скачивание файла

    GET /download-folder — скачивание папки в ZIP

Сценарии использования

Программа идеально подходит для:

    Веб-приложений с функцией файлового менеджера

    Систем обмена документами внутри организации

    Резервного копирования через API

    Интеграции с другими системами через REST
